🌩️ ABOUT THE PROJECT

STORM CYBER MD is a messaging automation project developed using JavaScript and Node.js.

It brings together WhatsApp automation, Telegram integration, command handling, group management and useful bot utilities.

Developer: STORM X

Location: Uganda 🇺🇬

📥 INSTALLATION

1. Clone the repository

git clone https://github.com/massyharriet979-blip/STORM-CYBER-MD-.git

2. Open the project

cd STORM-CYBER-MD-

3. Install dependencies

npm install

4. Configure your environment

Set up the required bot configuration and credentials.

5. Start the bot

node index.js

---

📁 MAIN FILES EXPLAINED

File| Purpose
"index.js"| Main bot entry point
"package.json"| Project information and dependencies
"config.js"| Bot configuration
"lib/handler.js"| Processes incoming messages and commands
"lib/context.js"| Builds message context
"lib/loader.js"| Loads command plugins
"commands/"| WhatsApp command files
"telegram/"| Telegram bot system
"whatsapp/"| WhatsApp automation features
"database/"| Bot data and settings
"sessions/"| Authentication session data
